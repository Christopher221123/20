# 20

Página de cumpleaños para Salomé, publicada con GitHub Pages.

## Cómo funciona
- `index.html`: contador regresivo hasta el 24 de noviembre a las 00:00 (hora de Ecuador, UTC-05:00). Antes de esa hora la línea de tiempo no se muestra.
- `timeline.js`: los hitos de la línea de tiempo. Se completa antes de la fecha de desbloqueo.

## Estado
- Contador publicado; la línea de tiempo se añade antes del 24 de noviembre de 2026.

## Notas
- Los datos de `timeline.js` son públicos en GitHub Pages, por lo que solo se añaden cuando el contenido esté listo.

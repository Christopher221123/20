# Diseño y decisiones

- **Idea:** una carta animada para Salomé por sus 20 años. Cuenta quién es ella (no una lista de fechas), en capítulos horizontales.
- **Estilo:** minimalista, fondo claro tipo papel, tipografía serif (Cormorant Garamond) + sans (Inter), un solo color de acento por capítulo.
- **Animaciones:** una ilustración lineal por capítulo que se dibuja al llegar (grupo juvenil, flor, huellas, ADN, niños, cine, ruta de viaje, ecualizador, 20 puntos). Al pasar el cursor sobre la ilustración se repite.
- **Navegación:** deslizar, rueda del ratón, flechas del teclado o puntos inferiores.
- **Contador:** llega a cero el 24/11/2026 (hora de Ecuador, UTC-05:00), pero la página sigue cerrada hasta que el autor decida abrirla (desbloqueo manual; reemplaza la fecha provisional 31/12/2026).
- **Contenido:** sin fechas exactas ni datos íntimos. Solo gustos, estudios, fe, mascotas y momentos compartidos.
- **Publicación:** GitHub Pages (rama `main`, carpeta raíz). Se desactiva después del cumpleaños.
